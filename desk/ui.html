Desk: keys

Write-only key store. Each service keeps a list of labeled keys; one is in use. Once saved, a key can never be shown again, here or anywhere: the page only knows its label, when it was saved, and which parts are filled in. You can add keys, rename them, replace their values, switch which one is in use, test them, and delete them (asks twice). Keys stay in this server's private data folder and are only sent to the service they belong to.
